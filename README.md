# TieTea Website

A bilingual Taiwanese tea brand website built as a static multi-page site for GitHub Pages hosting.

## Pages

- Home
- About
- Collections
- Premium Blends
- Brewing Guide
- Tea Story
- Gift Boxes
- Journal
- Sustainability
- FAQ
- Contact

## Run locally

```bash
cd 2020
python -m http.server 8000
```

Then open: http://localhost:8000

## GitHub Pages

Push the repository to GitHub and enable GitHub Pages from the main branch or `docs/` folder.
